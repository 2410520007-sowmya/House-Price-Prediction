# House Price Prediction

## Project Overview

This project predicts house prices using a Machine Learning Linear Regression model.

## Objective

The main objectives of this project are:

- Load and explore a housing dataset.
- Clean and analyze the data.
- Select relevant features.
- Split the dataset into training and testing sets.
- Train a Linear Regression model.
- Evaluate the model using RMSE and R² score.
- Generate example house-price predictions.
- Save the trained model.

## Dataset

The project uses the California Housing dataset available through Scikit-learn.

The dataset contains 8 input features related to housing and geographical information.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- GitHub

## Machine Learning Algorithm

Linear Regression was used to predict house prices.

## Methodology

1. Load the dataset
2. Explore and analyze the data
3. Check for missing values
4. Select features and target variable
5. Split data into training and testing sets
6. Train the Linear Regression model
7. Generate predictions
8. Evaluate the model
9. Interpret model coefficients
10. Save the trained model

## Model Performance

- RMSE: 0.746
- R² Score: 0.576

The model explains approximately 57.6% of the variation in house prices.

## Example Predictions

The project generates predictions by comparing actual house prices with prices predicted by the Linear Regression model.

## Result

The Linear Regression model successfully predicts house prices and demonstrates the basic workflow of a supervised machine learning regression project.
